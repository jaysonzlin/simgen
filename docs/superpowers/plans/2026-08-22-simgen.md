# SimGen Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create a self-contained remote-GPU sample generator that converts Gaussian-splat object scenes into reproducible MPM, render, trajectory, and optional observation-point-view packages.

**Architecture:** `simgen` separates pure CPU contract code from GPU runtime adapters. The CLI resolves YAML into immutable metadata, writes every artifact to a staged sample directory, and invokes narrowly scoped simulation, rendering, downsampling, and optional point-view/video stages. Adapted NGFF code lives under `simgen/ngff_runtime/` behind SimGen-owned interfaces; the rest of the project never imports the sibling NGFF checkout.

**Tech Stack:** Python 3.10+, PyYAML, NumPy, h5py, PyTorch/CUDA, Warp, Taichi, gsplat, OpenCV, Pillow, Grounding DINO, SAM2, pytest.

**Spec:** `simgen/docs/superpowers/specs/2026-08-22-simgen-design.md`

## Global Constraints

- `simgen` must not import `edited-neural-gaussian-force-fields` at runtime.
- Default object root is `simgen/data/GSCollision/objects`; YAML can override it.
- Default sample timeline is 49 frames at 24 fps; default render size is 480 by 480.
- `view_0` is stationary and every frame must use the recorded camera-0 pose.
- Emit no PLY files.
- Each object HDF5 has one persistent frame-zero FPS selection of exactly 2,048 points.
- RGB is `clip(SH_C0 * shs[:, 0, :] + 0.5, 0, 1)` where `SH_C0 = 0.28209479177387814`.
- Raw MPM HDF5s, foreground point views, and trajectory video are optional and disabled by default.
- CPU tests must not initialize CUDA, Warp, Taichi, Grounding DINO, SAM2, or gsplat.
- The `simgen` directory is not currently a Git repository; do not run commit commands unless the user initializes it.
